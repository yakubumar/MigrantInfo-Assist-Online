# MigrantInfo Assist — Online

Мақолани ҳавола ёки матн орқали киритинг: дастур уни мигрантлар учун содда русчага қайта ёзади, сарлавҳалар таклиф қилади, ўзбекчага таржима қилади ва Word ҳужжатига сақлайди.

## Онлайн жойлаштириш (ноутбук ва смартфон)

Лойиҳа responsive дизайнга мосланган: браузерда очилади ва смартфон экранига мослашади. Онлайн манзил олиш учун бир марта хостингга жойлаштириш керак. Ушбу лойиҳа Render'га мос конфигурация билан келади.

1. Лойиҳани GitHub'да янги репозиторийга юкланг.
2. https://render.com сайтида аккаунт очинг ва **New → Blueprint** ни танланг.
3. GitHub репозиторийни уланг ва `render.yaml` орқали сервисни яратинг.
4. Render муҳитида `GEMINI_API_KEY` қийматига ўз Gemini API калитингизни киритинг: https://aistudio.google.com/apikey
5. Deploy тугагач, Render берган `https://...onrender.com` манзилини ноутбук ва смартфонда очинг.

**Муҳим:** API калитини кодга ёки GitHub'га қўшманг. У фақат Render'нинг Environment Variables қисмида сақланиши керак. Бепул тарифда сервис узоқ вақт ишлатилмаса ухлаб қолиши ва биринчи очилиш секинроқ бўлиши мумкин.

## Компьютерда ишлатиш

- Windows: `START-Windows.bat`
- Mac/Linux: `./start-mac-linux.sh`

Локал манзил: `http://localhost:3000`

## Асосий имкониятлар

- Мақолани ҳавола ёки матн орқали киритиш
- Мигрантлар учун содда русча рерайт
- Бир нечта сарлавҳа варианти
- Ўзбекча кирилл таржимаси
- Русча ва ўзбекча матнларни таҳрирлаш
- Word (.docx) экспорти

## Эслатмалар

- Айрим сайтлардан мақолани ҳавола орқали олиш чекланган бўлиши мумкин; бундай пайтда матнни қўлда қўйинг.
- Онлайн ишлаши учун Gemini API калити ва интернет керак.
- Бу версиянинг ўзида мақолалар архиви қурилмалар орасида автоматик синхронланмайди. Агар архив ва сақланган қораламаларни ноутбук/телефон ўртасида синхронлаш керак бўлса, кейинчалик база ва аккаунт тизими қўшилиши лозим.
